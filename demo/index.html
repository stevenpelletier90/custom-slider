Put the engine on the site

Once per site, not once per slider. Link the files if you can upload them; paste the code if you can’t. Either way it is the same two files, and the slider above is running the very ones you would take.

Link to the files

Best choice — every page that links them shares one cached copy.

<link rel="stylesheet" href="/path/dl-carousel.css">
<script src="/path/dl-carousel.js" defer></script>
Where these go The <link> in Style Only → Head Section, the <script> in Body Section, Bottom. Swap /path/ for wherever you uploaded them.
