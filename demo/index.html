Step 1 — put the engine on the site (once per site)

Two ways in. Link to the files if you can upload them; paste the code if you can’t. Either way it is the same two files, and the slider above is running the very ones you’d be taking.

Link to the files

Best choice. Upload both files once, and every page that links them shares one cached copy.

<link rel="stylesheet" href="/path/dl-carousel.css">
<script src="/path/dl-carousel.js" defer></script>
Where these go The <link> in Style Only → Head Section. The <script> in Body Section, Bottom. Swap /path/ for wherever you uploaded them.

Or paste the code

For a site where you can’t upload files. Copy each file’s contents straight into the page. It is fetched live from this demo, so it can never be a stale copy.

dl-carousel.css
dl-carousel.js
Where these go Copy gives you the wrapper too. The CSS <style> goes in Style Only → Head Section; the JS <script> goes in Body Section, Bottom — it must load after the markup, or it finds nothing to wire up.
