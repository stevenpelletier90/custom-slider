    Once per site, not once per slider. Link the files if you can upload them; paste the code if you can’t. Either way the slider above is running the very ones you would take.

    Link to the files

    Best choice — every page that links them shares one cached copy.

    <link rel="stylesheet" href="/path/custom-slider.css">
<script src="/path/custom-slider.js" defer></script>
    Two files, that’s all The stylesheet carries the card styling as well, so a slider you copy from here is mostly just its markup. Without these two files linked, a pasted slider is a plain list.
    Where these go The <link> in Style Only → Head Section, the <script> in Body Section, Bottom. Swap /path/ for wherever you uploaded them.

    Or paste the code

    For a site where you can’t upload files. Fetched live from this page, so it can never be a stale copy.

    custom-slider.js
    Where these go Copy gives you the wrapper too. The <style> in Style Only → Head Section; the <script> in Body Section, Bottom — it has to load after the markup or it finds nothing to wire up.
