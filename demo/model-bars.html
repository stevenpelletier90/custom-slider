Model bar library

All 55 model bars across the 76 OEM demo sites are one design — arrows, swipe, one card per step, a sliver of the next card peeking, and never autoplay. The only brand-to-brand difference is how many cards show at each width. Every strip below is that one design running live on a different brand’s ladder; resize the window and watch the counts change.

Each section carries its complete copy-paste pair. Do the Start here step from the main demo once per page first. For screenshots of the real sites instead, see the screenshot library and the census.

The outliers — not this design

Four census entries are not the standard model bar. Each one is already demonstrated live on the main page.

  • Kia demo 1 and the Lexus quick-nav are centre-mode: the active card sits centred with neighbours peeking. That is the peek pattern with the peek turned right up.
  • Hyundai demo 1 folds the lineup into two rows — the two-row grid.
  • Subaru’s strip is content cards stepping a whole page at a time — the default behaviour shown by featured vehicles.
