Model bar library

All 90 model bars across the 129 OEM demo sites are one design — arrows, swipe, one card per step, a sliver of the next card peeking, and never autoplay (the only autoplaying strips anywhere are one group site’s make and location rails — not model bars — shown last on this page). Brands differ in two ways only: the ladder (how many cards show at each width) and the look (what the cards wear — plain white, a gray or black band, a colour tile behind each car, photo cards). Every strip below runs live on a different brand’s ladder wearing that brand’s look; resize the window and watch the counts change.

Where one ladder ships with two looks in the estate, both are shown — same breakpoints, different clothes, same engine. Each strip carries its complete copy-paste pair. Do the Start here step from the main demo once per page first. For screenshots of the real sites, see the screenshot library and the census.

Not the standard design

The official non-slider family, and the census entries whose live builds sit on the main demo page.

Model bars that are not sliders

A recurring official family, not a one-off: several OEMs ship their model bar as a static grid or tab panes with no carousel at all. Porsche and INFINITI run hover-reveal tile grids, one Ford variant is a plain CSS grid (see the main page's ladder table), BMW's is tab panes with a text rail — one pane per model, and on phones it simply becomes a stacked list (the tabs demo shows the wiring). And clients drift here too: one Nissan store replaced its slider with a tabbed static grid. If a request says “model bar”, check which family before reaching for the slider.

Hover-reveal tile grid

As the Porsche demo ships it: square photo tiles, two across on phones, six across on desktop. At rest a tile is just the photo; hover (or keyboard focus) darkens it and slides up the name with Search New / Search Used links. Below 992px the label and links simply sit under the photo — no hover choreography on touch.

The outliers — not this design

A few census entries are not the standard model bar. Each one is already demonstrated live on the main page.

  • Kia demo 1 and the Lexus and Nissan quick-navs are centre-mode: the active card sits centred with neighbours peeking. That is the peek pattern with the peek turned right up — and it now has company as a model bar proper: the Maserati spotlight above is the same recipe.
  • Hyundai demo 1 folds the lineup into two rows — the two-row grid.
  • Subaru’s strip is content cards stepping a whole page at a time — the default behaviour shown by featured vehicles.
  • Ford demo 5 has no slider at all: a static flex-wrap grid of models, six across on desktop down to two on phones. Once a one-off, now a documented family — see model bars that are not sliders above.
