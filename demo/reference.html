Custom Slider no dependencies

Build Patterns Reference

Reference

A scroll-snap carousel with no runtime dependencies, built to replace the third-party sliders on DealerOn sites. The CSS owns layout and physics — the track is a native scroll container, so swipe, momentum and snapping all work before any JavaScript runs and keep working with JavaScript off. The JavaScript only adds controls into space the CSS already reserved.
