Model Bar Library

Every distinct model bar across the 76 OEM demo sites, screenshotted from the live pages at 1280px. Fifty-five sites run a model bar and they share one anatomy — arrows only, one card per click, no autoplay — so what you are comparing below is how many cards each brand shows, and whether it groups them under tabs.

The numbers behind this are in the OEM Slider Census.

Plain model bars

One strip, arrows only, no grouping. 25 of the 55 sites look like this. The only thing separating them is how many cards they show at each width.
